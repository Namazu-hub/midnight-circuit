# v4.10.0 — 1面の仕上げと科研費による復帰

2026-11-14。今回の対象は1面と、全8面共通の科研費・復帰処理。6面の新たな再設計は含まない。

## 現行仕様

- 残機を廃止。HP0または手動リトライのたびに科研費¥50を支払い、HP6でチェックポイントへ復帰する。
- 残高¥50なら支払って¥0で復帰できる。¥0だけでは終了せず、次の復帰時に支払えなければゲームオーバー。
- HPが残る通常落下は従来どおりHP−1。復帰費用は発生しない。
- ゲームオーバー後の再挑戦は進行・収集・周回・科研費をリセットし、1面・¥0から開始。自己ベストと設定は保持する。
- 通常の配置敵は撃破から18秒以上たち、出現地点が画面外かつPICOから300px以上離れたときに再出現する。再出現ごとに撃破報酬を受け取れ、回数制限はない。同じ死体からの二重報酬は禁止。
- 4面・6面の通常配置敵と回路試験の警備敵にも適用。工具供給敵、捕獲した重り、地形化した敵、追走イベント、造形ジョブ、ボスは既存の専用再供給・復旧処理を維持する。フィーバーは対象外。
- 自販機の残機購入を撤去。費用を使い切った場合は敵から稼ぎ直せる。

## 1面

工具リフトは初回¥10。料金を払うまで隔壁の上下を迂回できない。支払い後のリフト再利用は無料で、空のリフトは自動で戻る。高所の任意パーツ、地下2室、既存の学生の会話を維持する。

最後の床ボタン配線は○→△→□。成功すると実際の出口橋が通電し、先のゴールに進める。配線盤から橋へケーブルを描き、パルスだけでは橋を開けない。料金表示と地下区画名も整理した。

## 実装と互換性

`recovery.mjs`が復帰費用を一元管理し、`enemy-respawn.mjs`が配置敵の初期状態と再出現を管理する。UIは費用・残高・不足を表示する。

セーブキーは`midnight-circuit-save-v1`のまま。`economyVersion:2`と`runOver`を保存する。旧セーブの科研費・進行・ベスト・保留フィーバーを保持し、旧`runLives:0`だけは終了状態として移行する。残っていた旧残機を科研費に換金しない。装置の途中状態を再読込から完全復元する機能は従来どおりない。

実行モジュールのURL版番号を4.10.0に統一し、旧キャッシュとの混在を避ける。
