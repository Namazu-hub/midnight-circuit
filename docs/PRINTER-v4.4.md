# ステージ4再設計（v4.4）

## 遊べる実装

- A 材料供給：スプール敵を重量プレートへ誘導。撃破してしまっても、高所の代替重りを運搬してC/操作で復旧できる。供給ベルトと上層経路を起動。
- B 押出：棚の24歯ギアを高所へ運び装着。下層レバーを操作すると48歯出力が逆方向・半速で回転し、搬送橋が開く。
- C 造形：進入で供給暴走。中層の遮断スイッチで樹脂の障害物を撤去しノズルを停止。上層で造形先を1→2へ切り替え、各3秒で橋を積層。完成前は衝突判定なし。
- D 冷却：高所の2基のファンと中層インターロックを操作し、不安定な足場を安定させる。高所には科研費・モンエナ・収集部品。
- E 専用アリーナ：直前の回復チェックポイントと補給自販機。Cで戦闘を開始し背後を閉鎖。1200pxの専用ビュー、HP/拘束バー、任意音声オン時の専用合成BGM。

DRAGON-01は9秒の積層・ノズル走査で登場。予兆付きの突進・尻尾・頭部・樹脂弾・風圧を切替。頭への踏みつけと近接パルスで損傷し、モンエナ中は2ダメージ。
HP12から援護ノズルが最大3体まで造形。造形途中のパルスで阻止でき、上層の供給装置で45秒停止可能。
HP6以降は通常攻撃だけでは停止しない。供給操作→中央へ誘導（重量プレート12秒固定）→経路切替→6秒の拘束フレーム造形→右上の冷却→右中層の緊急停止。
第三フェーズは造形床が上下動。停止後は隔壁を開き出口へ。ボス報酬¥250は一度だけ。

## 保持と復帰

ステージ順、セーブキー、PICO基本操作、モンエナ、科研費、残機、通常クリア後のフィーバーを保持。他7ステージのLEVELS定義はv4.3と完全一致確認済み。
死亡・任意リトライ時、道中修理は維持。運搬中の部品は棚へ戻る。戦闘のHP・敵造形・拘束・回復装置・造形床を初期化し、入口へ戻す。従来の残機消費に従う。
通常ステージ途中の全状態をブラウザ再読込後に復元する機能は従来通り未対応。

## コード

- printer-level.mjs：ステージ4の形状・装置・探索配置
- printer.mjs：道中の修理・固有敵・事件・ボス状態・再挑戦
- printer-art.mjs：オリジナルCanvas描画（翼・角・多関節首・尾・積層外装・コア）
- tests/printer-route.mjs：座標/HP改変なしで開始→全設備→全フェーズ→ゴールの入力ドライバー
- tools/printer-preview.html：セーブを使わない描画検証用シーン

v4.3の固定ピン試作は現行ステージ4から撤去。旧action-repairsとhand-routeは履歴参照用に残し、現行回帰試験は新しい装置経路を対象とする。

## 検証

構文・参照検査、57件の自動テスト成功。8ステージ到達、スプール先行撃破後の代替攻略、未完成足場、暴走障害物、冷却条件、修理報酬、隔壁、ボスリセット、製造上限、拘束順序、報酬の重複防止を含む。
入力ドライバーは経路を知った自動操作であり、初見プレイヤーによる通しプレイ・所要時間の測定ではない。
スマートフォン実機、長時間プレイの発熱・性能、BGMの聴感、初見難易度は未検証。

## 品質上の残作業

機能の通し経路は実装したが、指示書の全演出を最終品質まで仕上げた版ではない。専用絵はコードによる多部品描画で、手描きスプライトの歩行・攻撃全コマは未制作。登場は走査ノズルと層の描画を重ねた近似で、実際の押出ツールパスの再現ではない。停止時の関節が順番に止まる演出、造形床破壊の破片演出は今後強化する。押し引き専用物理は追加せず、代替重りの運搬で攻略する。
