# 素材の追加・差し替え

現版に追加の素材ファイルは不要。キャラクター・背景・立体文字はCanvas、UIの一部はSVG、音声はgame.mjsのSynthが生成する。docs/*.jpgは既存の画面記録で、ゲームから読み込まない。

将来の素材受け入れ用にassets/images、assets/bgm、assets/sfxを用意した。**ここに置くだけではゲームへ反映されない。** 今回は実行コードの完全一致を優先し、ローダーの追加は行っていない。

次段階で実際に配信する素材をdist/assets/に置き、相対URLのマニフェストとフォールバック付きロードを追加する。画像の差し替え先はrender.mjs/fever.mjs、音はgame.mjsのSynth。従来の描画・合成音をフォールバックとして残す。

素材には用途、作者/出典、使用許諾、元サイズ、透過、ループ範囲、音量目安を記録する。変換前の原本も別保管する。ステージ番号や効果音イベントと対応付ける。

音設定と一時停止を尊重し、再生失敗や読込待ちで進行を止めない。デコード負荷、同時発音、音量、遅延は実機で検証する。
