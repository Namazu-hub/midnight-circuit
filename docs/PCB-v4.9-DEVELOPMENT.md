2026-10-29 JST。前回の共通ゲート・ステージ4修正に続く実装。**完成版ではなく、work/v4.9-pcb-factory上の開発版。公開main/Pagesはv4.8のまま。**

## 今回つながったゲームプレイ

A電源ユニットを押して主電源復旧 → Bステンシル位置と往復スキージ／ペースト → C速度の違う2枚のPCBを乗換え、ノズルの部品配置で足場形成 → Dジャンパ線接続と正逆転・電磁石 → E冷却で溶融はんだを固体の橋へ → F静止したPICOをAOIが認識して持上げ → G実装ロボット4段階 → H操作可能な後日談と通常ゴール。

FのOK/NGは実際の搬送ゲートに連動。NGはS「不良品保管庫」へ、再検査でOKへ戻せる。保管庫の往復は無料で閉じ込めない。7工程＋H＋任意Sの9部屋で、ステージID6と全8ステージの順序を維持する。

電源接続・工程完了には既存の一回修理報酬を利用。任意の保守プレス、関節校正と完全修理ボックス、ネジ落下装置を残した。これにより既存112件を含むテストの期待値を変えずに保守機能を維持した。

### 地形と操作

- 移動PCBには銅箔、シルク、パッドを描く。2枚は異なる周期・位置で動く。実装予定部品は破線、配置後は実体のある足場。ノズルから0.6秒で降下した瞬間に有効化し、重なったPICOは上面へ逃がす。
- 基準マークを切り替えると未実装部品の配置が30pxずれる。パルスは吸着中の部品の配置を開始できる。配信された部品は挑戦内で保持。
- PCB乗り遅れ時も基板は周期運行を続ける。落下は従来のHP−1・チェックポイントへ。最後の乗換えの着地点を広げ、通常速度・装備なしの経路で死亡0を確認した。
- 電源は接近して移動方向を押すと低速で押せる。入口の再供給端末と落下時の復帰がある。傾斜・ベルトによる電源の自重搬送は未実装。
- Dのベルトは正転・停止・逆転を持ち、床に乗るPICOを運ぶ。短いジャンパ線は既存の固定長tetherを再利用。磁石で鉄フレームを上下させ、配線＋持上げで工程が完了。
- Eは温度230から冷却し、55以下で橋が実体化。熱い状態は足場ではなく、接触ダメージ。予熱・保温・溶融・冷却の表示はあるが、4つの独立温度プロファイルではなく共通温度の簡略モデル。
- Fは測定床で静止1秒→部品認識→PICOを載せた持上げ床が上昇。空床だけ上昇する不具合を修正し、PICOが300pxより上へ運ばれる試験を追加した。乗換えジャンプは従来入力。

### ボスの初期実装

1. カメラ照準→予告→ノズル降下→停止後の隙へパルス。
2. 部品が順に配置され、高所へ登る足場になる。フィーダー停止で一定時間供給を止められる。
3. 逆転でヘッドを左の取付位置へ動かし、その位置で電磁石を有効にすると固定。局所冷却で温度が下がると拘束成立。
4. 上層AOIでNG判定→可動ヘッドが排出位置へ移動・降下→露出コアへ接近して最後のパルスが必要。遠くからの自動勝利はない。撃破報酬¥250は一度だけ。

再挑戦ではボスHP・製造部品・装置を初期化し、道中の工程復旧は保持する。コアは4面と同じ描画の侵食分体で、黒幕全体の消滅とは扱わない。終了後はHへ進み、通常のfinishを発行する。

### 敵・会話

はんだボール、ツームストーン、QFP、吸い取り線、ブリッジ、ポップコーンIC、ウィスカーの7種・8体を初期配置。跳動・倒伏・巡回・帯電解除・冷却反応・破裂予告・周期的な伸長を持つ。パルス・工具・踏みつけと一度だけの科研費報酬へ接続。

**各敵の攻略利用はまだ未完成。** QFPの背に乗る、ツームストーン連鎖、破裂で障害物を破壊、吸い取り線によるブリッジ除去などは未実装。フィーダーヘビ、煙、はんだごてドローンも未実装。敵数・配置・強弱は初期値。

指定の導入会話、実装・基板REV等の小ネタ、旧6面の全セリフ、後日談5行を保持・追加。Aの電源復旧前後で学生のセリフが切替わる。Hでは完成基板とCOMPONENT NOT FOUND: PICOを表示。学生の作業アニメーションや夜明け専用美術は未完成。

## 残る作業・未実装

- PCBの主経路は成立するが、探索・戦闘密度、機械の迫力、説明なしで理解できるかを人間のプレイで調整する必要がある。完成版v4.9として公開しない。
- キャリアテープの運搬／巻取、電磁石の極性・反発、部品の再供給によるパズル、電源の斜面・ベルト搬送、断熱カバー、独立した4温度区間、炉の脱出イベントは未実装。
- 静電気の量は保持・接地・吸い取り線で解除するが、全精密機器の誤動作や強化パルスの全戦闘判定への統合は未完成。
- ステンシルは位置と高さが変わるが、穴の配置による複数経路の本格パズルは未完成。スキージは押すが、物体まで押す剛体モデルではない。
- 部品は3スロット固定。全5部品・回転・自由位置への配置ではない。主基板がライン終端へ運ばれる一方向搬送ではなく、安全に再乗車できる往復モデル。
- AOIの持上げとOK/NG分岐は実装したが、吸着ヘッドの専用運搬アニメーションは簡略化。ボス本体の造形と攻撃は初期段階で、複数ノズル、カメラ連続点灯、工場停止・無音・侵入の音響演出、弱点の多様性を作り込む必要がある。
- 不良品保管庫以外の隠しルート、抵抗色パズル、モンエナ専用区間、基板裏面、リール内部は未実装。
- ステージ4の施錠C扉の通常UIでの到達確認、全11部屋の手動往復、報告落下地点の特定、スマホの多行条件表示は引き続き未確認。自動経路成功で代用しない。
- 実機iPhone Safari/Android Chrome、複数指、音質、性能・発熱、初見所要時間、セーブ再開の端末間確認は未実施。性能改善を主張しない。
