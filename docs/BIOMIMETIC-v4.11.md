# v4.11 — 東郷研究室・人体模倣

2面を温室から人体模倣研究室へ置き換えた。添付マップの横方向の幹、縦坑、上下の枝、合流という構成を参照し、元画像の画素やキャラクターは使用していない。新しい背景・敵・機構はCanvasによるオリジナル描画。

10,000pxの連続した世界に8区画。前室→腱ワイヤー巻取り塔→関節リンク回廊→屈伸縦坑→把持実験台が主経路。上層の拮抗ワイヤー室、下層の掌機構整備室、終盤の精密ピンチ標本室が任意の枝で、3個の収集部品を配置。薄い上階床と左右の整備階段で上下の層を行き来する。

ワイヤーで吊った上下リフト、滑車、腱を引く三指リンクを描画。2つの関節校正パズルを解くと実際に指骨橋の衝突面が有効になる。単なるパルス中の仮足場ではない。校正は既存の関節修理モデルを用いる。手形の敵は既存の予告突進AI、骨型は跳躍AIを使い、無限再出現と科研費報酬に対応。新しい専用戦闘AIではない。

旧2面の全会話は研究生へ引き継ぎ、研究テーマの会話も追加。8面の順序・セーブキー・旧2面のクリア記録は維持。科研費初期0、復帰50円は共通仕様のまま。

検証: 構文・相対参照検査、全テスト。通常入力の主経路で2面を死亡0でクリア、2つの校正パズルを操作。従来の温室専用テスト（滴定と葉の再生）は独立fixtureへ移し、機構モデルの検証を保持。巻取り塔の折返しと縦坑の下降も入力経路で検証。追加試験で区画・敵形状・部品配置と校正橋の衝突、復帰後の維持を確認。

ブラウザの描画fixtureで関節橋を確認。fixtureは地点指定の検査で、人間による通しプレイではない。任意の全枝を人間が通した操作感、スマートフォン実機、初見所要時間は未検証。
