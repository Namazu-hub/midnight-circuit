## 操作と実装範囲

近くの「⚙ 修理 / 再調整」またはCで開く。以前から必須のサービス装置はXでも開く。任意装置の近くではXを戦闘用に維持。敵・物理・ステージ時計は修理画面中に停止する。中断時は入力値をその挑戦内で保持する。Escで中断。ネイティブの選択欄・スライダー・増減ボタンを使用し、縦横の狭い画面では独立スクロールする。

| 方式 | 操作・判定 | 難度の変化 |
| --- | --- | --- |
| 配線 | 端子の名前を読み接続先を選択。接続先の重複は前の線を外す | 3/4/5本。電源・信号・接地の3本が必須、予備線まで一致で完全 |
| 歯車 | 出力12/24/48歯、中間歯車0〜3個。目標速度と回転方向を満たす | 目標速度比と中間歯車の許容数が変化 |
| 中和滴定 | 塩基5/1/0.1/0.01mL、酸0.1mLを投入。pH7に合わせる | 酸の濃度・体積と応急許容幅が変化。無料リセット可能 |
| 関節 | 相対関節角を調整し、点線の目標姿勢に重ねる | 2/3/4関節。最大誤差10°以下で応急、2°以下で完全 |
| 信号 | 基準波形に位相・周波数・振幅を合わせる | 位相のみ→周波数も→振幅も。波形全体のRMS誤差で判定 |
| センサ | 閾値と感度で、既知の物体あり/なしの測定点を分類する | 単一→感度調整→2センサのAND。誤検知/見逃し合計2以下で応急、0で完全 |
| 論理回路 | AND/OR/XORと最終NOTを選び、表示された真理値表を一致させる | 単一ゲート→2ゲート・3入力→NOTを含む条件。全行一致が必須 |

全方式にLv.1〜3の生成・判定があるが、全21問を通常面に配置したわけではない。複雑な配線の分岐・中継端子、歯車の複数出力や自由配置、関節の障害物回避、任意配線の論理回路エディターはまだ実装していない。最適化の第3評価も未実装。

## 報酬と状態

修理助成¥40、完全修理で追加¥30。ミニゲームを持つ装置の高所ボックスは完全修理で解錠し、取得で¥75。応急→完全への再調整では差分の¥30だけ支給する。報酬フラグ・修理ランク・装置効果は死亡/手動リトライで保持。ステージを新しく開始する場合は新しい挑戦となり再取得可能。通常面の途中状態はブラウザ再読込を越えて保存しない（科研費残高・クリア実績などは既存仕様で保存）。

修理画面の詳細ヒント¥10、応急自動補助¥80は任意。購入済みヒントの再表示は無料。復旧済み装置への補助は課金しない。無料操作で全種類を解ける。リザルトに完全修理数を追加し、フィーバー保留結果にも含まれる。

モデルはrepairs.mjs、画面はrepair-ui.mjs、配置と効果はrepair-stations.mjs、報酬はresearch.mjs。engine.mjsが修理セッション中の更新を止める。状態は装置ID、puzzleType、difficulty、puzzle、on、repairRank、repairResult、rewardPaid、bonusPaid、effectApplied、researchLinkで管理。

## 科学モデルの根拠と限界

- 歯車：外歯平歯車の単純歯車列。出力/入力角速度は、噛み合いによる符号反転と入力歯数/出力歯数から計算。中間歯車の歯数は速度比の大きさから消える。[KHK歯車技術資料](https://www.khkgears.co.jp/gear_technology/basic_guide/khk351_1/)、[CMU Mechanisms / Gears](https://www.cs.cmu.edu/~rapidproto/mechanisms/chpt7.html)。画面の歯形は模式図で、インボリュート歯形の設計器ではない。
- 中和：25°Cの一価強酸・強塩基、体積加算、理想溶液を仮定。残存酸濃度をCとして、H−Kw/H=C（Kw=10^-14）を数値的に安定な形で解く。等量付近の急変を再現し、弱酸・緩衝液は対象外。[OpenStax Chemistry: Atoms First 2e 14.7](https://openstax.org/books/chemistry-atoms-first-2e/pages/14-7-acid-base-titrations)。教科書の25mL・0.1Mの例をテストで照合。
- 関節は平面リンクの順運動学、信号は正弦波、センサは固定の模擬測定データ。現物の装置や研究室を再現するものではない。ゲームの事故・暴走はフィクション。
