# v4 研究室拡張

2026-10-26。v3の8コース、旧セーブキー、残機、落下ダメージ、モンエナ、音・演出軽減、学生会話を保ち、既存の物理・Canvas描画に追加。

## 追加内容

- 台車以外のコースに高さ110刻みの4段サービス足場とチップ。1・6面は終盤の高所制御盤もクリア必須。
- 順番接続（1・6面）：Xを3回、電源→信号→接地を接続。
- 中和滴定（2面）：Xで一滴ずつ投入し、ゲーム用の簡略メーターをpH1→3→5→7へ。実際の滴定曲線のシミュレーションではない。修理後は薬液を無害化。
- 位相調整（4・7面）：動くマーカーが緑の帯にあるときX。4面では修理後にノズルを停止し造形床を常時使用可能にする。
- 修理は出口の解放条件。追加装置の修理時はHP1回復と復帰地点の更新。6面の制御盤はプレスの危険を解除。
- 1・6面にネジ落下区間。黄色い縦線の予告後に4列で落下、パルスで除去可能。
- 台車3面の中盤に上・中・下のレール。Q/Eまたは画面の上段/下段で隣のレーンへ移行。各レールに敵とチップ、既存の切れ目ジャンプ、終点で合流。台車の接触で敵を撃破。
- 横伸びバネ、引力・反発を使うコイル、混ざると粘着壁になるシリコーンA/B、猛ダッシュ・跳ね・不審・追跡の4種のネズミ。既存5種に8種を追加。粘着壁はパルスで除去、12秒で消滅。
- 最終面にプレイヤーより大きい暴走ロボット。予告→突進→隙の周期。隙の頭を踏むか磁力制御装置の近くでXで暴走ゲージを削る。6回で停止し、近くでXで再起動して初めて出口が有効。
- 指定の学生セリフ3行を原文で追加。
- フィーバーのコンボ時に指定の理系成功メッセージ3行と追加2行を表示。
- フィーバー抽選から最終面を除外。ステージ順が任意でも1周に1回、残りの抽選対象面をすべて終えるまで未当選なら最後で保証。1面構成なら対象がないので抽選なし。既存pendingセーブの復帰は維持。
