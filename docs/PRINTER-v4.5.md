## 実装した内容

### 部屋と探索

| 区画 | 部屋・役割 | 移動と修理 |
| --- | --- | --- |
| A | フィラメント倉庫 | ロール・ベンチー・キューブを重量プレートへ誘導。敵を失っても棚の重りを運べる |
| B / B2 | 押出機構 / 搬送ダクト | 上層の扉からダクトを探索し交換ギアを回収。ショートカットでソケットへ戻り、駆動レバーを操作 |
| C / C2 | 造形室 / 上部制御室 | 暴走で通路に樹脂が発生。上部遮断装置を操作し、階段・橋・遮蔽物を実物のレバーで切替・造形 |
| D / D2 | 冷却・保守室 / 冷却塔 | 高所の2ファンと安全インターロックを復旧。保守リフト経由で戻り、不安定な床を恒久足場にする |
| S | 試作品保管室（任意） | Aの高所から入る。試作品、学生、収集部品、科研費、大型搬送ベンチー |
| E | DRAGON-01 アリーナ | 回復チェックポイント・自販機のある静かな前室から隔壁を開け、歩いて進入 |

通常の扉は往復可能。部品回収地点からの出口は安全な一方向ショートカットで、元の部屋へは入口側の扉で戻れる。部屋切替では同じゲームインスタンスを保持する。HP、残機、科研費、モンエナ残時間、敵撃破、収集済み品、修理状態を作り直さない。暗転中に座標を移す通常扉と、連続移動するボス隔壁を区別する。遷移中は被弾・物理・効果時間の消費を停止する。

配線滑走はC／操作でつかまり、通常ジャンプで離脱。大型ベンチー・上下リフト・回転足場・搬送ベルトは既存の足場物理を使用。修理済みの供給機構・駆動機構が別室の搬送機械にも電力を供給する。高所に科研費・モンエナ・部品・制御装置、下層に戦闘ルートを配置する。各追加室の入口と出口付近にチェックポイントを置く。

### 見た目による誘導

- 固い足場：明るい連続した上面、暗い輪郭、側面のボルト模様。
- 未完成：半透明の破線。選択した造形パターンの輪郭と積層を描き、完成までは乗れない。
- 冷却前：破線・熱の線・警告色。冷却すると連続した上面へ変わる。
- 移動足場：軌道、方向表示。ベンチーは屋根が乗れる面。
- 装置：空のギアソケット、運搬時の輪郭、制御盤の図柄、配線を流れる光で因果を表示。
- 通常時の攻略文章を削減。進展のない状態が18秒続くと装置・配線を強調。「？」を押したときだけ7秒の短文ヒント。再度押すと具体化。横画面でも利用できる。
- 学生の雑談は攻略指示と別扱い。接近時に6秒表示し、10秒の間隔を設ける。改行と画面内への配置、縮小率に応じた文字サイズを使用。

### 固有敵

固定配置25体、8種。現在いる部屋だけ通常敵AIを動かす。工場の追加製造は総数4体・同時生存2体まで、ボス援護は既存どおり最大3体。

| 敵 | 行動・相互作用 |
| --- | --- |
| フィラメントロール | 坂で加速、追跡、重量プレート、他の敵を轢く |
| 通常ベンチー | 予兆後の突進、乗れる屋根、重量プレート |
| 造形不良ベンチー | 絡まった樹脂と予兆付きの跳躍 |
| キャリブレーションキューブ | 跳躍・移動、乗れる上面、重量プレート、他の物体を押す |
| サポートツリー | 枝による攻撃、足場兼用の枝、根元をパルスで破壊 |
| 多関節タコ | 高所から触手を伸ばす。上面は足場として利用可能 |
| 絡まりフィラメント | 伸縮して足元を妨害。供給遮断で無力化 |
| 暴走プリントヘッド | 赤い予兆から樹脂を落とす。遮断装置で停止 |

撃破報酬は一度だけ。屋根に乗っている場合は接触ダメージを避け、屋根外での踏みつけ・パルスで倒せる。造形された通常ベンチーにも屋根の当たり判定を追加する。樹脂弾は敵にも当たり、造形した遮蔽物で止まる。

### DRAGON-01

専用Canvas描画を刷新。14の独立した関節、結晶状の頭と角、連続する背びれ、層の筋、偏光風の配色、内部コア、破損外装を描く。既存画像や参考商品の形を複製しない。

左右の向きには105pxの不感帯と1.5秒の変更間隔を設け、頭から体、尻尾へ追従させる。描画と頭・胴・尾・コア判定は共通の `dragonPose` を使う。攻撃後の頭へのパルスと、左右いずれの頭への踏みつけが有効。突進前の圧縮、首の打ち下ろし、尾のしなり、被弾反動、停止時の関節の順次停止を追加。

9秒の登場中にノズルが各関節を順に積層し、後半で頭が現れる。再挑戦のスキップを保持。3フェーズ、援護造形の阻止、材料供給停止、中央への誘導、造形経路切替、拘束フレーム、冷却、緊急停止の流れを保持する。ヒントを要求しない限り長い攻略手順は表示しない。停止後はノズルの動作と警告色を止め、出口を開く。報酬¥250は一度だけ。

ボス入場はPICOとカメラを1.6秒かけて連続移動し、隔壁を閉鎖。専用カメラ・HPバー・任意音声オン時の専用合成BGMは既存機能を維持。敗北・任意リトライでは従来どおり残機を消費し、通常区画の修理を保持したままボス入口へ戻す。ボスHP、拘束、援護、回復装置、造形床を初期化する。

### 学生

指定15種類は `PRINTER_CHAT` に原文で収録。8番は2人分の発言を一つの吹き出しに収録。他の指定済み雑談を削除していない。10人を通常の各部屋に配置し、修理前後・ボス停止後で反応を切り替える。材料交換、工具、ベンチー試作品、サポート材などの小物と簡単な動作を追加。ボス戦のアリーナには学生を置かず、前室に配置する。

## 未検証・残る品質上の課題

この版はプレイ可能な拡張版であり、全指示の完成度目標を達成したと判断していない。

1. **初見10〜15分は未測定**。既知の入力経路は約2分で終わる。迷わずに内容で10〜15分を確保できたと主張しない。初見プレイヤーによる計測と内容・敵配置・探索報酬の再調整が必要。
2. 全分岐・全任意造形を含む人間の通しプレイは未実施。自動入力の完走と、固定描画確認を区別する。
3. スマートフォン実機の長時間・複数指操作、iOS Safari、BGMの聴感は未確認。小型横画面ではキャラクターが小さくなるため、実機の視認性を継続評価する。
4. 拡張部屋には共通の足場構成が残る。下層戦闘と高所報酬、固有機械は追加したが、全分岐の難度と所要時間の差は未調整。
5. ドラゴンはコードによる多部品アニメーション。手描き全コマのスプライトではなく、翼を使う本格的な飛行や造形床の大規模破片演出は未実装。風圧時の浮き上がりはある。
6. 登場は部品別積層とノズル追従のゲーム用近似で、実際の押出ツールパス再現ではない。
7. 暴走事件は樹脂障害・警告灯・追加造形・上部遮断・ケーブル／リフトによる移動で表現。専用の制限時間付き脱出レースは追加していない。
8. 通常面途中の状態をブラウザ再読込から全復元する機能は従来どおり未対応。部屋移動と同一プレイ内の死亡・リトライでは状態を維持する。
9. 参考Amazonページは取得できなかったため、ユーザー記載の多関節クリスタル竜の特徴に基づくオリジナル描画。商品素材の流用なし。
