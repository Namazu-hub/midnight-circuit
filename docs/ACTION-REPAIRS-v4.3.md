# v4.3：PICOによるステージ内修理の試作

対象は既存ステージ4「3Dプリンターの夢」の入口ハンド。全7方式の変換ではない。

## 操作と結果
- 棚の金色の固定ピンに触れて1個運搬。移動・二段ジャンプ・パルスは従来通り。
- 番号順に関節へ運び、Cまたは画面の装着ボタンで取り付ける。
- 緑の受付時間内に新しいパルスを発射すると関節固定。残留パルスは無効。
- 直すたびに次の高所足場と橋の1区間が開通。約0.6秒の駆動後に衝突判定が有効になる。
- 固定済み関節はチェックポイント。落下でHP減少、運搬中の部品は元の棚へ戻り、装着済み部品と修理状態は維持。
- 3関節で応急修理、科研費報酬。入口端末で既存の関節精密調整を行うと完全修理、追加報酬と箱を解錠。
- 精密調整画面はPICOと端末の接続を表示。応急修理前の画面起動は不可。
- 科研費の補助購入は判定時間と回収範囲を拡大。修理完了の代行はしない。
- 元の造形ルートも維持。モンエナ・通常戦闘・他ステージは既存仕様。

## 実装
`action-repairs.mjs` が部品/関節状態、接触入力、タイミング、段階的地形、描画を担当。
装置の actionRepair に completed/nodes/parts/assisted、部品に loose/carried/installed、関節に installed/locked/deploy を持つ。
既存の repairs.mjs の rank、research.mjs の一度限りの報酬、engine.mjs のチェックポイントに接続。
今後は歯車運搬や配線部品を同じ部品・接触の構成で追加する。現時点の他6方式は従来の精密操作画面のまま。

- tests/hand-route.mjs は開始地点から座標/HPを書き換えず入力のみで3関節の応急修理を完了。死亡0。人間のプレイ時間や面白さを評価する試験ではない。
- 部品の落下復帰、装着保持、緑時間/新規パルス判定、未修理足場の通り抜け、補助の重複購入防止、精密調整の前提、報酬重複防止を確認。
- 既存8面の自動到達、残機、フィーバー、保存互換、タッチ入力解除テスト成功。
