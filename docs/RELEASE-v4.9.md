## 通常の入口と進行

公開ルートはdist/index.html → game.mjs。通常タイトルと8面の選択から開始する。
検証用tools/*-replay.htmlへの誘導や記録入力の実行は不要。
1面は終盤の記号床ボタン1か所で配線し、地下ログは任意の順序ヒント。
4面は共有の扉条件・現在目標・復帰経路と既存ドラゴン戦を保持。
6面は通常開始→製造工程→Dの回路試験塔→コイルと搬送回路→炉→AOI→
PLACE-MASTER 9000→後日談H→通常ゴールへ接続。道中・ボスの進行に
検証画面から状態を注入する必要はない。通常のクリア・保存・抽選処理を使う。

packageを4.9.0、全ランタイム参照URLを4.9.0へ統一。RULES、8面ID、
ステージ順、localStorageキーは変更しない。公開版の旧セーブは同じキーで
読み込む。別オリジンのテストSiteの保存内容は自動移行しない。

## 確認と限界

公開前にcheck、193件の自動テスト、8面の入力経路、printer-routeと
pcb-routeを再実行。経路は通常開始から移動・ジャンプ・ACTION・PULSE等で
通常ゴールまで進める。既知解の自動入力であり、人間の初見通しプレイではない。
セーブ・残機・科研費・フィーバーの回帰は既存テストで確認する。
ブラウザの公開版起動確認とActionsの結果は実行後に報告する。

既存HANDOFF / CIRCUIT-TOWER / PCB開発記録の未完成事項は残る。
特にコンデンサの時間差を利用する新解法、全室の立体再設計、全ボス段階の
発見型設計、実機スマホ、多指操作、音質、人間の初見理解・面白さ、
最終版のブラウザ通しプレイを、この公開だけで確認済みとは扱わない。
