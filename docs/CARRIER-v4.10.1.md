# v4.10.1 — 充電キャリアの必須乗り継ぎ区間

2026-11-14。1面を8,400pxから11,400pxへ延長。地下保守室の出口（x7150）を通過した地上のx7500–10500を足場のない空中区間とし、地下探索の迂回路には置かない。既存の終端の配線・出口・敵・アイテムは3000px先へ移動する。

3台の充電キャリアを乗り継ぐ。各台は3秒の充電後、上昇・下降を含む折れ線を90px/sで約12秒かけて走行する。乗車ごとに科研費¥10を支払い、ジャンプや被弾で離れた後の再乗車も新しい乗車と数える。同じ台に立ち続けても追加徴収しない。残金不足では乗車を拒否する。終点では乗客がいる間は待機し、空になって6秒後に自動帰還する。

区間全体に6か所、合計3000pxのネジ落下帯を配置。軌道の高低差に合わせて高所からネジが落下し、既存の予告とパルスによる除去を維持する。区間の下端y700を越えるとHP0となり、科研費¥50で復帰、支払不能ならゲームオーバー。復帰時は3台とも出発位置へ戻る。出発直前にチェックポイントと自販機を設ける。初期科研費は新規開始・ゲームオーバー後とも¥0、既存セーブの残金は保持する。

主な変更: bench-level（延長・配置）、bench-machines（軌道・料金・帰還）、bench-machine-art（同じ軌道の表示）、engine（区間限定の落下死）、laboratory（ネジの発生高度・寿命を区間ごとに設定）。その他の実行モジュールはキャッシュURL版番号を4.10.1へ更新。

検証: npm run check、npm test（216件成功）。通常入力ドライバーは3台に実際に乗り、1面を約81秒、死亡0、HP4、残金¥50で完走。ネジによる被弾・再乗車分の料金も含む。単体検査では連続乗車の追加課金防止、再乗車時の課金、落下死と復帰費用、3台の復帰、初期残金0、足場による迂回路がないこと、地下区画との非重複、ネジ帯の全長を確認。従来の短い任意キャリア試験を新たな長距離有料区間の試験へ更新した。
