# 回路試験塔：代表区画の設計と再利用契約

2026-11-04 JST。正式リリースではなく、v4.9作業ブランチの代表区画。

## 場所と操作

既存のS「不良品保管庫」を幅2400pxの回路試験塔に再設計した。部屋IDは増やさず、FのNG搬送からの往復を残す。Dの高所（x6480、床y400）からも入れる。試験塔の左側からはいつでも退出でき、上層出口のみ加速試験の完了を要求する。主製造工程A–Hのクリア条件は変えない。

| 段階 | プレイヤーが試すこと | 観察できる因果 | 失敗時 |
| --- | --- | --- | --- |
| 上段・R | 突進方向を誘導し、R輪郭に着座した敵をACTIONで固定 | クランプと導線が点灯 | パルス・踏みつけで一時停止。工具で倒しても2秒後に再供給 |
| 下段・C | 跳ねるCを輪郭へ誘導して固定 | 入出力の波形が変化 | 固定解除、未固定部品再供給が可能。金銭報酬はない |
| 色帯 | 上段へ戻り、1k / 10k / 100kΩを切替えて比較 | 小さいRは波打ち、大きすぎるRは電圧不足。適切ならリフトが安定・上昇 | 値は循環し、永久に失敗しない。下層の左帰還棚でやり直す |
| 上層・整流 | 3端子部品を運び、ダイオードを正方向へ反転 | 右側LOADの導線が点灯 | 逆方向ではパルスを撃っても駆動しない。反転し直せる |
| 駆動 | 3端子ソケットへ部品を取り付け、近くで新たにPULSE | 駆動アームが降下して実体足場になる | 遠方パルス／過去のパルスでは動かない。冷却待ち後に再入力 |
| 加速 | コイル上でJUMPし、空中で二段目を使い右上へ | 通常ジャンプでは届かない340px上の出口床に到達 | 落下先は連続保守床。修理を維持してリフトへ再乗車 |

通常時は接続数と信号の状態を短く表示し、解法全文は出さない。数値・帯色・パッド輪郭・配線・波形・装置の運動で因果を示す。18秒停滞後の局所点滅と「?」端末の3段階任意ヒントがある。色だけで判別させない。

## 電気モデルとゲーム上の省略

`circuit-model.mjs` は描画・地形に依存しない一次遅れモデル。Vin = 5 + 2sin(2π·4t) V、C=100µF、負荷100kΩ。直列抵抗Rを変更し、定常利得はRload/(R+Rload)、時定数は(R∥Rload)C。指数積分で電圧を更新し、60Hz・最大60点の実データをオシロに描く。波形画像を切り替えるだけの演出ではない。

1秒分の窓を取得後、出力3.8–5.2V、リップル0.3V未満が0.5秒継続した場合に安定判定する。10kΩで約4.5V、100kΩでは約2.5Vになり、単に大きい値を選ぶだけでは解けない。切断時の減衰も計算する。

基礎資料：Analog Devices [RC low/high-pass lab](https://wiki.analog.com/university/courses/electronics/lp_hp_filters)、[Engineering discovery lab 5](https://wiki.analog.com/university/courses/engineering_discovery/lab_5)。ゲームの定数・負荷・合格帯は独自設計。

ダイオードは順逆の論理ゲートであり、順方向電圧降下・降伏を計算しない。トランジスタは信号で別電源24Vの負荷を駆動するスイッチの抽象化で、アナログ増幅率を再現しない。コイルは通電した床上からの上向き射出で、磁場積分・加速段数・位相合わせは扱わない。現実の回路安全設計の教材とはしない。

## 地形と状態の境界

- 下層保守床y650、入口床y510、帰還棚y580。全落下先を通常探索床に分類し、左端で装備なし帰還可能。
- リフトはy620–210を100px/sで往復。未安定時は実測リップルに応じて小さく揺れ、下へ戻る。乗り遅れても再到着する。
- 上層制御床y150、終端床y−190。コイル初速980px/sは `TOWER` 定数。既存 `RULES`、通常・二段ジャンプは不変。
- アームは降下99%以上でのみ衝突有効。未完成時は破線。乗員がいる間は電源喪失でも撤去しない。
- 死亡時は固定済みR/Cと実装済みトランジスタを保持。運搬中のトランジスタは棚へ戻る。部屋移動でも運搬を解放。
- 固定前の敵が範囲外へ出た場合は復帰。敵は2体まで、再供給から科研費を得られない。
- コイル使用後に上層床へ着地すると試験完了、¥80を挑戦内で一度だけ付与。左側出口は常時使用可。
- ページ再読込時の全装置状態の永続復元は新設しない。既存セーブキー・フィーバー・ステージ順・HP上限を変更しない。

## 責務と再利用

| モジュール | 責務／契約 |
| --- | --- |
| circuit-model | 入力R/C/帯番号とdtから電圧・リップル・安定判定。地形や成功報酬を参照しない |
| circuit-level | Sの配置、Dへの接続、パッドと操作盤のデータ |
| circuit-tower | 敵の誘導・固定・再供給、運搬、装置状態、局所報酬 |
| circuit-art | 上記と同じ状態から波形、輪郭、導線、可動部を描画 |
| pcb-factory | 既存の制御対象探索、移動足場、判定、更新の入口へ接続 |
| engine / rooms | 死亡／扉移動時の運搬解放。通常walkは変更しない |

純粋なRC計算はそのまま別室へ再利用できる。塔のアクション層はこの1室に限定され、汎用の任意回路グラフエディタではない。他室へ展開する場合、対象座標と装置効果を明示してアダプターを作り、`circuit-tower` の絶対座標をそのまま複製しない。`pcbManaged` のdx/dyを二重適用しない。

## 再現手順

```sh
npm run check
npm test
node tests/routes.mjs
node tests/printer-route.mjs
node tests/pcb-route.mjs
node tests/circuit-route.mjs
RECORD=1 node tests/circuit-route.mjs
```

最後のコマンドはQA用の入力記録を再生成する。`dist/tools/circuit-replay.html` は通常の6面開始から入力を再生して選択地点へ進み、手動プレイへ切替可能。ゲーム状態をDOMから注入しない。通常製品UIとは異なる検証画面で、セーブを使用しない。

実プレイ入口は6面Dの高所RC扉。QA画面の「帯の試験」はR固定後、「逆方向試験」は上層に部品を運搬した直後。「手動プレイ」後にCまたはACTIONで変更し、数値・配線と動作を比較する。
