# ステージ6：発見と操作をつなぐ設計基準

**考えるから突破できる。操作が上達するから突破できる。両方を使いこなすから最後に勝てる。**

仕組みの数、操作回数、テスト数を完成の指標にしない。目的と失敗理由は伝えるが、解法の順序は押し付けない。電子回路の暗記・計算・総当たりを要求しない。

## 各区画を評価する四つの瞬間

| 段階 | 必要な体験 | 確認すること |
|---|---|---|
| 最初に見る | 届かない高さ・大穴・停止した機械。その先の目的地 | 危険と目的を、失敗する前に見通せるか |
| 試す | 敵を踏む、誘導する、信号を流す、経路を切り替える | 誤操作にも違いの分かる反応があり、戻せるか |
| ひらめく | 邪魔だった敵が部品になる。安定した電源で足場が変わる | 一つの原理を知る前後で、行動が変わるか |
| 突破する | 起動した機械を使い、跳び、着地し、加速する | 解答後も本人の操作が必要で、成功が気持ちよいか |

## 共通の原理を応用する

- 抵抗：踏むと値が変化し、電源と機械の状態が変わる。
- コンデンサ：信号の安定から、将来は蓄積・時間差・一時給電へ発展させる。現行実装に時間差パズルがあると報告しない。
- ダイオード：向きの数を増やすより、経路がどの装置を動かすかを見せる。同時使用できない装置を順に利用する余地を作る。
- パルス：敵の一時停止と、トランジスタを介した大型装置の制御で共通操作を応用する。
- コイル：謎解きの報酬を高速移動という新しい行動に変える。普通のジャンプでは届かない地形と、空中操作・着地の技術を組み合わせる。

## 禁止する近道

平床に装置を並べる、数値を理由なく総当たりさせる、反転回数だけ増やす、説明文で順番を解説する、敵の外見だけ部品にする、理解済みの手順を長く繰り返す、見えない奈落や戻れない安全床を作る。

## 評価と継続判断

既知解の経路テストは到達性・再挑戦性の検証であり、発見・緊張感・爽快感を保証しない。初見プレイでは最初の仮説、試した行動、失敗理由の理解、ひらめいた瞬間、理解後に操作を上達させた場面を記録する。

現行の整流回路はAC/DCの代替経路を持つが、装置間の電力配分パズルには至っていない。終盤のR→C→SWは実体の搬送・足場変化を伴うが順序が強く固定される。この二点は設計の次の課題であり、単に操作盤を増やして解決しない。
