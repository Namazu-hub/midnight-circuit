# MIDNIGHT CIRCUIT — 真夜中の修理屋

夜の研究室を探索するブラウザ用2Dアクションゲーム。通常8ステージ、レール台車、3Dプリンター内部、学生の会話、科研費による復帰、抽選フィーバーを収録しています。

v4では高所ルート、3種類の追加修理、ネジ落下、8種類の追加敵、3段レール、暴走ロボット戦を追加しました。旧セーブの記録と8ステージの順番を維持します。

## v4.10.1：必須の充電キャリア区間

地下保守室の出口より先に3,000pxの空中搬送区間を追加。上下する3台のキャリアを乗り継ぎ、乗車のたびに¥10を支払います。充電は3秒、移動は約12秒／台。区間全体でネジが降り、落下は即HP0で科研費¥50の復帰へ移ります。初期科研費は¥0です。[変更と検証](docs/CARRIER-v4.10.1.md)。

## v4.10.0：1面の仕上げ・科研費で復帰

1面は¥10の工具リフトを使わないと進めない配置にし、最後の配線修理で出口の橋が開きます。全8面で残機を廃止し、HP0・手動リトライは科研費¥50、払えない場合はゲームオーバー。配置敵は画面外で何度でも再出現し、撃破のたびに科研費を稼げます。詳細・互換性・検証の限界は[更新記録](docs/RELEASE-v4.10.md)を参照してください。

## v4.9 通常ゲームへの統合

1面の研究机・地下サーバールーム、1か所の床ボタン式配線修理、4面の進行案内と復帰経路、6面のPCB製造工程・回路試験塔・コイル移動・実装ロボット戦を通常ゲームへ統合。上記の「ゲームを開く」から通常タイトル・ステージ選択で遊べます。検証用replayページや自動操作は不要です。

8面の順序、既存セーブキー、HP・科研費・フィーバーは維持（残機はv4.10で科研費による復帰へ変更）。途中の装置状態をページ再読込から完全復元する機能は従来どおりありません。テストSiteのセーブは別オリジンのため公開版へ自動移行しません。

公開範囲と確認の限界は[通常配信記録](docs/RELEASE-v4.9.md)に記載しています。従来の全企画案が完成したという意味ではなく、実装済みのゲームプレイを公開本体へ反映した版です。

## v4.9.3：1面の必須リフトと配線の視認性

工具リフトで越える高い隔壁を設け、不要なパルス足場を撤去しました。リフト初回起動と1面のモンエナ取得にはそれぞれ科研費¥10を使います。リフト再挑戦は無料で、所持金不足による詰みを防ぎます。当時は敵の再出現後に報酬を受け取れませんでしたが、v4.10で繰り返し稼げる仕様に変更しました。地下サーバー室の壁材と最後の3本の配線表示も改善しました。詳細は[1面の実装記録](docs/STAGE1-MAP-v4.9.md)を参照してください。

## v4.9.2：1面の足元ボタンと探索アクション

工具リフト、10秒間の延長トレー、乗って充電する搬送キャリアを通常の1面に追加。高所のアイテムへ向かう任意ルートとして遊べます。必須の配線修理は1か所を維持し、地下2室の役割も保持しています。窓外の奥行き、地下照明、落下中のカメラ追従を調整しました。検証範囲と再挑戦方法は[1面の実装記録](docs/STAGE1-MAP-v4.9.md)に記載しています。

## v4.5：ステージ4の探索拡張

5区画を9つの部屋に展開。扉、搬送ダクト、隠し試作品保管室、配線滑走、大型ベンチー、冷却塔を追加。装置はC／既存の操作ボタンで操作し、必要なときだけ「？」で短いヒントを表示します。ドラゴンは14関節のクリスタル造形竜に変更し、左右への振り向きと当たり判定を共通の姿勢モデルで動かします。

実装範囲・検証・残課題は[PRINTER-v4.5](docs/PRINTER-v4.5.md)。初見10〜15分の目標時間とスマートフォン実機の操作性は未検証です。通常面途中の再読込からの完全復元は、従来と同じく未対応です。

## 起動

通常は[ゲームを開く](https://namazu-hub.github.io/midnight-circuit/)だけで遊べます。パソコン・スマートフォンとも同じURLです。公開処理の状態は[GitHub Actions](https://github.com/Namazu-hub/midnight-circuit/actions/workflows/deploy.yml)で確認できます。

### 手元で開発する場合

ビルドやnpmパッケージのインストールは不要です。Python 3がある環境で、このフォルダーから実行します。

~~~sh
python3 -m http.server 8000 --bind 127.0.0.1 --directory dist
~~~

ブラウザで http://127.0.0.1:8000/ を開きます。ESモジュールを使用するため、index.htmlのダブルクリック（file://）ではなくHTTPで配信してください。実行にはNode.jsやChatGPTは不要です。

## 操作

| 操作 | キー・画面操作 |
| --- | --- |
| 移動 | ← → / A D |
| 二段ジャンプ | Space / Z / ↑ / W |
| パルス | X / Shift |
| 一時停止 | Esc / P / 一時停止ボタン |
| チェックポイント再開 | R または一時停止画面のボタン（科研費¥50、不足時ゲームオーバー） |
| 台車 | 左で減速、右で加速、台車ごとジャンプ。3段分岐ではQ/Eまたは上段/下段ボタンで切替 |
| スマートフォン | 画面の左右・ジャンプ・パルスボタン |

スマートフォンは左右とジャンプ／パルスを同時に押せます。指をボタンの外へずらすとその入力を解除します。横向きでプレイするとステージ一覧を隠し、ゲームと操作ボタンだけの表示になります。回転時は誤操作防止のため一時停止するので「冒険をつづける」を押してください。画面の向きが変わらない場合は端末の回転ロックを解除してください。

HP6、科研費¥0で開始。落下はHPを1失い、HP0または手動リトライで科研費¥50を支払います。支払えなければゲームオーバー。再挑戦で冒険の進行をリセット。モンエナは9秒間の虹色加速です。音は任意で初期状態はオフ、演出軽減設定があります。

## 開発チェック

Node.js 22以上（今回の確認環境は24）。依存パッケージのインストールは不要です。

~~~sh
npm run check
npm test
npm run verify:baseline
~~~

最後のコマンドは移行時の元版との一致検査です。今後ゲームを意図的に変更した場合、不一致になるのが正常です。基準ハッシュを書き換えて差異を隠さないでください。テストだけで実機の操作感や音質は保証できません。

GitHub PagesのSourceはGitHub Actionsを選択します。`.github/workflows/deploy.yml`がmainへのpush時に構文・参照チェックとゲームの自動テストを実行し、両方成功するとdist/のみを公開します。ビルドや依存パッケージのインストールは不要です。テスト失敗時は公開せず、直前の公開版が維持されます。

セーブはブラウザのlocalStorageに保存され、別URLへ自動では引き継がれません。ソースのバックアップと各ブラウザのセーブデータは別です。

## 修理システムの改修（v4.2）

7方式の修理を専用画面に追加しました。装置の近くで **「⚙ 修理 / 再調整」または C**。従来から必須だった修理装置はXでも開きます。任意装置のそばでもXは戦闘パルスとして使えます。

配線の接続先、歯車の歯数、滴定の投入量、関節角、信号、センサの閾値、論理ゲートを操作して復旧します。無料で何度でも調整でき、修理中は時間停止。応急修理から完全修理へ改善すると追加報酬と高所ボックスを解放します。3Dプリンター面には橋になるアーム、台車には停車ブレーキ、時計塔にはリフト校正、最終面には砲台射撃の停止装置を追加しました。

[修理の操作・配置・検証・未実装事項](docs/REPAIRS-v4.2.md)

8面を新しい研究室テーマに作り替える作業、8〜12分への拡張、新しいOROCHI戦は引き続き未実装です。v4.1の上記記録にある「7種未実装」は当時の状態で、v4.2では基本7方式を実装しました。高難度の分岐配線・複数歯車出力・関節の障害物回避などは未実装です。
